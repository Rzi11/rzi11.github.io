# Site de Win N3oum ?

Le site de présentation de l'app, en ligne sur https://rzi11.github.io/

L'app elle-même vit dans un autre dépôt, `Rzi11/WinN3oum`, et reste à https://rzi11.github.io/WinN3oum/

## Contenu
- `index.html` : la page du site (tout est dedans : textes, styles, carte de Djerba)
- `confidentialite.html` : ce que l'app garde et envoie
- `fonts/`, `icons/` : les mêmes que dans l'app
- `img/qr-app.svg` : QR code vers l'app
- `img/partage.png` : l'image qui s'affiche quand on partage le lien (WhatsApp, Instagram…)

## Modifier
- Les plages de la carte : tableaux `COTES` et `PLAGES` dans `index.html` (repris de `plages.json`).
- Pas de build : on modifie les fichiers et on les dépose sur GitHub.
